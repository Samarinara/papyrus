# English dictionary

`words.txt` is the alphabetic English word list from
https://github.com/dwyl/english-words/blob/master/words_alpha.txt,
downloaded on 2026-09-16, normalized to lowercase, deduplicated, and
filtered to 2–16 letters. The upstream license is included in LICENSE.md.

The file is served locally; gameplay never calls a third-party dictionary API.
This broad dictionary includes uncommon and archaic words.
